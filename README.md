# SocialGroups

Once upon a time, like a year ago, I started on a plugin to make social groups / clubs in Minecraft. Then I stopped making it. Now I'm making it again. Also, things have changed with Paper.

This is mostly being purpose-built for UWMC, but if you come across this and think you'd like to use it - go for it! With proper credit!

SocialGroups allows players to connect with others who share similar interests - think factions without the competition.

This README is still in progress. It'll get updated as I add more here.
